## Stale Data Cleanup

When a diagnostic, audit, or routine task surfaces stale data in any memory system (ctx_knowledge, auto-memory, MEMORY.md), fix it immediately. Do not ask permission to correct clearly outdated facts. Report what was changed after the fact.

This applies to: wrong version numbers, deprecated tool references, old model names, removed files still referenced, dead paths.
