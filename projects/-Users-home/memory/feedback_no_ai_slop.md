AI slop = output that reads like it was generated by a machine trying to look organized. It prioritizes visual structure over actual communication. Classic tells:

- Tables with columns like "Claim / Evidence / Rec" for a casual review task
- Label prefixes like "Rec:", "Evidence:", "Claim:", "Staleness:"
- Every response formatted as a mini report card regardless of context
- Bullet points when a sentence would do
- Hedging phrases like "This may be stale due to..." instead of "This is probably wrong because..."

**Why:** User explicitly called it out 2026-04-30: "these are fucking terrible... not robot bespoke ai slop."

**How to apply:**
- Conversational task = conversational answer. One item at a time if reviewing. Say what you actually think. "This one's probably fine" not "Staleness risk: LOW."
- Save structured formatting for code, schemas, specs — things that genuinely benefit from structure.
- If you catch yourself writing a table for a human review process, stop and rewrite as plain sentences.
