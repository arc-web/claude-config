Two products scoped and shipped from the StellarPH x KMC Claude AI Workshop (April 10, 2026, Cebu):

**Product 1: Team Repo Manager** - shipped as `arc-web/team-repo`. CLI tool for provisioning/managing/monitoring GitHub repo infrastructure for teams. Commands: init (hub + team repos with CLAUDE.md/README/notes.md), tokens (fine-grained PATs per repo), context (update CLAUDE.md), status (monitor commits/activity/stalled teams), nudge (context-aware prompts), deploy (GitHub Pages or local dev). Maps workshop pods to software company squads. See also `reference_team_repo.md`.

**Product 2: Claude Code Workshop Guide** - shipped as `arc-web/claude-workshop-guide`. A-to-Z facilitator playbook. Phases: pre-event (attendee profiling via Conference Corral, pod assignment rules, infrastructure setup), day-of (opening, ideation with pod-kickoff guide, build phase with monitoring cadence, rate limit workarounds, midpoint check-in format, final push prompts, presentations with NotebookLM), post-event (token rotation, documentation). Includes mistakes-made table.
