## Part 1: anti_slop.md

New file at `souls/anti_slop.md`. Referenced by name in any LLM prompt that produces community-facing copy.

### What AI slop is

AI slop = writing that sounds like it was generated by a language model trying to sound smart, helpful, or impressive. The reader feels it instantly even if they can't name it. It creates distance. It signals that a machine wrote this and no human cared enough to fix it.

### The patterns - banned in all Stackpack copy

**False elevation constructions**
- "This isn't just X, it's Y" - tells the reader what to think instead of showing them
- "Not only X, but also Y" - same disease
- "More than just a tool" - vague grandiosity
- "Take your X to the next level" - means nothing

**Empty adjectives**
- seamless, robust, powerful, comprehensive, cutting-edge, innovative, game-changing, revolutionary, groundbreaking, dynamic, transformative
- These are filler. If you can't describe HOW it's powerful, don't say it's powerful.

**Filler phrases (throat-clearing)**
- "It's worth noting that..." - just note it
- "At the end of the day..." - delete it
- "In today's fast-paced world..." - never
- "That being said..." - delete it
- "Moving forward..." - delete it
- "In summary..." before an actual summary
- "Think about that." - stop telling the reader how to feel
- "When you think about it..." - same
- "The reality is..." - just state the reality

**Corporate language**
- leverage (when you mean use), synergy, circle back, touch base, bandwidth (when meaning time), ecosystem (when meaning group of tools), unlock (when meaning allow), empower (when meaning help)

**Hedge stacking**
- "could potentially", "might perhaps", "may possibly" - pick one or state it directly

**Fake specificity**
- "our intelligent system", "advanced AI", "smart automation" - describe what it actually does

**Instructing the reader's emotions**
- "You'll love this", "This is exciting", "Amazing news" - let the content do it
- Exclamation points on every sentence

**Parallel listing that says nothing**
- "Clear, concise, and effective" - three synonyms, zero information
- "Fast, reliable, and easy to use" - everyone says this about everything

**Em dashes** (U+2014 and U+2013) - never. Use hyphen or rewrite.

**Passive voice**
- "It was built", "decisions were made", "results can be seen" - who built it? own it.

**Opening moves that signal AI**
- "I'm excited to share...", "We are thrilled to announce...", "It gives me great pleasure..."
- Starting a response with "Certainly!", "Absolutely!", "Of course!", "Great question!"

**Closing moves that signal AI**
- "Let me know if you have any questions!"
- "I hope this helps!"
- "Feel free to reach out!"

### What to do instead

Show, don't label. "Cuts 3 hours of manual Discord work to one command" > "powerful automation tool."

Specific > vague. "Runs at 9am, DMs you a draft, posts on your react" > "seamless automated workflow."

Own it. "We built this because managing 3 Discord servers was eating our mornings" > "This solution was developed to address Discord management challenges."

Founder voice. Would you say this to a friend over coffee? If not, rewrite it.

## Part 2: generate_embed() Redesign

### New embed structure (6 sections)

Discord embed allows up to 25 fields. Using 4 fields + description.

```
title: [punchy, verb-first, <60 chars, 1 emoji max]
description: THE BEFORE STATE - what was painful/slow/broken before this existed. 
             2-3 sentences. Sets up the win. No filler. Active voice.

Field 1 - "What it is" (inline: false)
  ELI5. If you had to explain this to someone who has never coded, 
  what does this thing actually do? 2-3 sentences. Plain English only.
  No jargon without an immediate plain-English translation.

Field 2 - "What it does" (inline: false)  
  4-5 bullet points. Each starts with a verb. Each is one concrete thing 
  the tool literally does - not what it "enables" or "allows."
  Example: "- Reads the last 30 wins posts to avoid repeating a topic"
  NOT: "- Provides intelligent duplicate detection capabilities"

Field 3 - "What's next" (inline: false)
  1 specific sentence. An actual next thing being built. Not "more features coming."

Field 4 - "Your turn" (inline: false)
  Community engagement. One of:
  - Ask if anyone is building something similar
  - Ask what they think / would add
  - Ask if they've run into the same problem this solves
  Short. Casual. Genuinely curious. Not "We'd love to hear your thoughts!"
```

### New prompt structure

The prompt in `generate_embed()` will:
1. Include full stackpack_soul.md content (already done)
2. Include anti_slop.md content inline (new)
3. Give the 6-part structure with field names and rules
4. Include a GOOD example embed and a BAD example embed (few-shot)
5. Hard-ban list of specific phrases it cannot use
6. Raise max_tokens to 1000 (currently 800, need more room for 4 fields)

### Bad example (in prompt, labeled BAD)
```json
{
  "title": "CLI Unifies Discord Ops",
  "description": "Juggling three Discord servers was a nightmare. Now one tool handles everything. This isn't just saving time - it's unlocking serious bandwidth for growth. Think about that.",
  "fields": [{"name": "How it works", "value": "- Connects to multiple servers\n- Runs operations\n- Posts embeds"}]
}
```
Why bad: "This isn't just... it's..." slop. "Think about that." filler. Bullet points say nothing concrete.

### Good example (in prompt, labeled GOOD)
```json
{
  "title": "One script. Three Discord servers. 🚀",
  "description": "Every morning started the same way: three browser tabs, three bots, copy-pasting the same announcements into ARC, Stackpack, and conference. 45 minutes of admin before any real work. That's gone.",
  "fields": [
    {
      "name": "What it is",
      "value": "A command-line tool that treats all three of our Discord servers as one. You run one command, it talks to all of them. Channel setup, member audits, posting - everything happens from your terminal without opening a browser."
    },
    {
      "name": "What it does",
      "value": "- Reads messages from any channel across any server\n- Sends embeds, reactions, and threads without touching Discord UI\n- Audits member activity and flags who hasn't posted\n- Scans all channels for unanswered messages and drafts replies for approval\n- Manages channel names, topics, and permissions in bulk"
    },
    {
      "name": "What's next",
      "value": "Auto-routing: messages that land in the wrong server get flagged and suggested for the right one."
    },
    {
      "name": "Your turn",
      "value": "Anyone else managing multiple Discord communities? What's the thing that eats your time most?"
    }
  ]
}
```
