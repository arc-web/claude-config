# Discord Buttons + Revise Modal for Daily Win HITL

## Context

Replace emoji reactions on the DM draft with real Discord buttons (Accept / Reject / Revise). When Revise is tapped, Discord shows a native popup (modal) where you type a revision note. The system regenerates the embed with that note and sends a fresh DM with buttons again. No Claude Code needed. Fully self-contained from your phone.

The mechanism: `discord.py` connects to Discord's WebSocket gateway outbound from Mac. Button clicks come in as events. No HTTP server, no VPS, no public URL required.

---

## How Discord buttons + modals work (no server needed)

`discord.py` maintains a persistent WebSocket connection to Discord. When you click a button in a DM, Discord pushes an `INTERACTION_CREATE` event through that socket. The bot receives it, handles it, responds. Modal submit works the same way. No inbound connections - the bot dials out.

## Button Message (components JSON)

Replace the current DM send in `daily_win.py post_embed()` with this payload shape:

```json
{
  "content": "Win draft for today:",
  "embeds": [{ ...embed... }],
  "components": [{
    "type": 1,
    "components": [
      {"type": 2, "style": 3, "label": "Accept",  "custom_id": "win_accept"},
      {"type": 2, "style": 4, "label": "Reject",  "custom_id": "win_reject"},
      {"type": 2, "style": 2, "label": "Revise",  "custom_id": "win_revise"}
    ]
  }]
}
```

Styles: 3=green, 4=red, 2=grey. No emoji needed - the color does the work.

## win_bot.py - Architecture

```python
import discord, asyncio, json, sys
from pathlib import Path
from daily_win import generate_embed, get_openrouter_key, post_embed_with_buttons, ...

STATE_FILE = Path(".cache/win_state.json")
MIKE_USER_ID = 949451361697804318  # int for discord.py

class ReviseModal(discord.ui.Modal, title="What should change?"):
    note = discord.ui.TextInput(
        label="Revision notes",
        style=discord.TextStyle.long,
        placeholder="e.g. Make the bullets more specific. The title is too vague.",
        required=True,
        max_length=600,
    )
    async def on_submit(self, interaction): ...

bot = discord.Client(intents=discord.Intents.default())

@bot.event
async def on_ready():
    await check_and_post_pending()

@bot.event  
async def on_interaction(interaction):
    cid = interaction.data.get("custom_id", "")
    
    if cid == "win_accept":
        await handle_accept(interaction)
    
    elif cid == "win_reject":
        await handle_reject(interaction)
    
    elif cid == "win_revise":
        await interaction.response.send_modal(ReviseModal())
    
    elif interaction.type == discord.InteractionType.modal_submit:
        note = interaction.data["components"][0]["components"][0]["value"]
        await handle_revision(interaction, note)
```

**`check_and_post_pending()`**: On startup, reads state file. If `pending` exists and `dm_message_id` is null, posts DM with buttons. Runs every 60s via `asyncio` loop so it catches new drafts generated by the 9am cron.

**`handle_accept(interaction)`**:
1. Defer response (buys 15min for async work)
2. Read state, get pending embed
3. Post embed to Stackpack #wins via REST
4. Update state: `published=True`, append to `posted_ids`
5. Edit the DM message: disable buttons, add "Posted to #wins" footer

**`handle_reject(interaction)`**:
1. Respond immediately (no async work needed)
2. Update state: mark skipped, append to `posted_ids`
3. Edit DM message: disable buttons, add "Skipped" footer

**`handle_revision(interaction, note)`**:
1. Defer response
2. Load soul + anti_slop docs
3. Call `generate_embed()` with `revision_note=note` appended to prompt
4. Post new DM with buttons
5. Update state: `dm_message_id` = new message ID, `revision_notes` = [note]
6. Edit old DM: disable buttons, add "Revised - new draft sent" footer

## daily_win.py Changes

1. **`post_embed()`** - add `buttons: bool = False` param. When True, add components JSON to payload.

2. **`cmd_draft()`** - remove `add_reaction()` calls. After saving state, DON'T post DM. Just print "Draft ready. Win bot will DM you." (bot's polling loop picks it up)

3. **`cmd_publish()`** - remove entirely. Bot handles publish.

4. **State file** - add fields:
   - `dm_message_id`: str | null - message ID of current button DM
   - `revision_notes`: list[str] - notes from any revisions this cycle

5. **`generate_embed()`** - add `revision_note: str = ""` param. If present, append to prompt: `\n\nREVISION NOTE FROM HUMAN REVIEWER:\n{revision_note}\nRewrite the embed addressing this note specifically.`
